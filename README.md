# MediCare – Medication Reminder App

## About the Project
MediCare is a simple healthcare web application that helps users organise, manage, and track their daily medication schedules.

## Features
- Add and manage medicines
- Set medication names, dosage, and timings
- Track medication status (Taken, Pending, Skipped)
- View medication history
- Dashboard with daily progress
- Search medicines

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## How to Run
1. Install Node.js.
2. Open the backend folder in the terminal.
3. Run `npm install`.
4. Configure your MongoDB connection in the `.env` file.
5. Start the backend using `npm run dev`.
6. Open `index.html` in your browser.
